## 🎬 Animation Timings

### Page Load Sequence
```
0ms     - Page renders
100ms   - Navbar animates in
200ms   - Hero section animates
300ms   - Title words appear (staggered)
500ms   - Buttons appear
600ms   - Float animation begins (continuous)
1200ms  - Light rays start pulsing (continuous)
```

### Scroll Animation
```
As user scrolls down, each section:
- Fades in (opacity: 0 → 1)
- Slides up (y: 30px → 0px)
- Cards appear with stagger (0.1s delay between)
- Happens only when section is 50% visible
```

### Hover Interactions
```
Mouse enters card:
300ms - Card lifts up (-8px) + scales (1.02)
300ms - Glow effect opacity increases
300ms - Icon scales up (1.1x)

Mouse leaves:
300ms - All reverse back
```

## 🌙 Dark Mode Version

Same visual layout, but:
- Background: Dark slate (950 → 900 → 800)
- Text: Light (50 → white)
- Cards: Dark with white/light borders
- Glows: More pronounced
- Gradients: Same but adapted colors

Example:
```
Light Mode:  White bg + slate text
Dark Mode:   Slate-950 bg + white text
             All gradients inverted for contrast
```
